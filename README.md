| Xbox Input | Axis / Button | Keys |
| :--- | :--- | :--- |
| Left Stick X (Left / Right) | Axis 0 | `A` / `D` |
| Left Stick Y (Up / Down) | Axis 1 | `W` / `S` |
| Left Trigger | Axis 2 | `E` |
| Right Trigger | Axis 3 | `U` |
| Right Stick X (Left / Right) | Axis 4 | `J` / `L` |
| Right Stick Y (Up / Down) | Axis 5 | `I` / `K` |
| Buttons A / B / X / Y | Buttons 1–4 | `Z` / `X` / `C` / `V` |
| D-Pad (POV 0) | POV 0 | Arrow Keys (incl. `Home`/`End`/`PgUp`/`PgDn` diagonals) |
